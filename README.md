# VC入退室ログBot

ボイスチャンネルに誰かが入ったり出たりしたら、テキストチャンネルに書き出して、VCで「〇〇さん入室」「〇〇さん退室」と読み上げるBotです。

```
10/10 21:05 🟢 なな が 🔊雑談 に入室
10/10 21:40 🔴 なな が 🔊雑談 から退室
```

- チャンネルを移動したときは「前のVCから退室」と「次のVCに入室」の2行が出ます
- ミュートや画面共有の切り替えでは何も出ません
- このPCで `start.bat` を動かしている間だけ動きます（PCを切ると、その間の入退室は残りません）

### 読み上げについて

- 読むのは入退室だけです。テキストチャットは読みません
- 誰かがVCに入るとBotもそのVCに入り、誰もいなくなったら抜けます
- Botは同時に1つのVCにしか入れません。別のVCで同時に人がいるときは、Botがいる方だけ読み上げます（テキストのログは全部のVCの分が出ます）
- 名前は10文字で切って読みます（`.env` の `SPEAK_NAME_MAX` で変更可）
- 声はWindowsに最初から入っている日本語音声（Haruka など）を使います。追加のインストールは要りません
- 読み上げがいらないときは `.env` で `SPEAK=off` にしてください

## 準備（最初の1回だけ）

### 1. Pythonが入っているか確認する

コマンドプロンプトで `py --version` か `python --version` を打って、`Python 3.10` 以上が出ればOKです。

出なかった場合は https://www.python.org/downloads/ からインストールしてください。インストール画面の最初で **「Add python.exe to PATH」にチェック** を入れてください。

### 2. Botのアカウントを作る

1. https://discord.com/developers/applications を開いてログイン
2. 右上の **New Application** → 名前（例：`VCログ`）を入れて Create
3. 左のメニューの **Bot** を開く
4. **Reset Token** → 表示されたトークンを **Copy**（このトークンはBotの合鍵です。人に見せたり、どこかに貼ったりしないでください）
5. 同じページの「Privileged Gateway Intents」は **全部オフのままでOK** です

### 3. Botをサーバーに招待する

1. 左のメニューの **OAuth2** を開く
2. 「OAuth2 URL Generator」で **SCOPES** の `bot` にチェック
3. 下に出てくる **BOT PERMISSIONS** で、`View Channels`・`Send Messages`・`Connect`・`Speak` の4つにチェック
4. 一番下にできたURLをブラウザで開いて、サーバーを選んで認証

### 4. ログを出すチャンネルを作る

サーバーにテキストチャンネル `vcログ` を作ります（名前は変えてもOK。変えたら次の `.env` にも同じ名前を書いてください）。

非公開チャンネルにする場合は、そのチャンネルの権限でBotに「チャンネルを見る」「メッセージを送信」を許可してください。

### 5. 設定ファイルを作る

1. このフォルダの `.env.example` をコピーして、名前を **`.env`** にする
2. メモ帳で `.env` を開いて、`ここにトークンを貼る` を手順2でコピーしたトークンに書き換えて保存

```
DISCORD_TOKEN=（コピーしたトークン）
LOG_CHANNEL_NAME=vcログ
```

---

## 起動

`start.bat` をダブルクリック。

最初の1回は必要なものをダウンロードするので少し時間がかかります。黒い画面に次のように出たら動いています。

```
ログイン完了: VCログ#1234（ログの出し先: #vcログ）
  - サーバー名: #vcログ OK
```

- 黒い画面を閉じるとBotも止まります
- `チャンネルなし` と出たら、手順4のチャンネル名と `.env` の `LOG_CHANNEL_NAME` が一致しているか確認してください

### PCの起動と一緒に動かしたいとき

`Win + R` → `shell:startup` で開いたフォルダに、`start.bat` のショートカットを置いてください。

## うまく動かないとき

| 症状 | 原因と対処 |
|---|---|
| `.env not found` と出る | 手順5の `.env` がない。ファイル名が `.env.txt` になっていないかも確認 |
| `Python not found` と出る | 手順1。インストール時に「Add python.exe to PATH」を入れ忘れている可能性あり |
| `Improper token` / `LoginFailure` | トークンが違う。Developer Portal で Reset Token して貼り直す |
| 起動はするけどログが出ない | チャンネル名の不一致か、Botにそのチャンネルへの書き込み権限がない（黒い画面にメッセージが出ます） |
| BotがVCに入ってこない | BotにそのVCの「接続」「発言」権限がない（黒い画面に `VCに入れなかった` と出ます） |
| VCに入るけどしゃべらない | 黒い画面に `読み上げ失敗` と出ていないか確認。Windowsの「設定 → 時刻と言語 → 音声認識」で日本語の音声が入っているか確認 |
